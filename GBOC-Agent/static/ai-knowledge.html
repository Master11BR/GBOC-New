2. Treinar (máquina com GPU)

O treino LoRA roda fora do servidor de backup, numa máquina com GPU NVIDIA (8 GB+ de VRAM para modelos 3B). Copie o .train.jsonl e use o script que acompanha o Agente:
GBOC-Agent\scripts\finetune\train_lora_gboc.py pip install unsloth trl datasets python train_lora_gboc.py --train gboc_diag_XXXX.train.jsonl --val gboc_diag_XXXX.val.jsonl --export-gguf
Detalhes em scripts\finetune\README.md. Recomendado: 30+ casos validados.
