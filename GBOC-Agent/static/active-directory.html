Executar Backup a Quente do AD DS

O GBOC coordena o NTDS VSS Writer para congelamento atômico do banco de dados `NTDS.dit`, transações `edb.log`, scripts e políticas GPO da pasta `SYSVOL`, registro `SAM`/`SECURITY`/`SYSTEM` e zonas DNS integradas.

Proteção contra USN Rollback

O backup do GBOC Agent respeita o ciclo de Tombstone Lifetime (180 dias) do Active Directory, garantindo que snapshots antigos não sejam restaurados incorretamente, o que provocaria corrupção de sequências USN e tombstone nas réplicas do domínio.

Gerador de Script para Restauração Autoritativa

Caso uma Unidade Organizacional (OU) inteira tenha sido deletada acidentalmente, a restauração autoritativa instrui o `ntdsutil` a aumentar o número de versão USN dos objetos em 100.000 para forçar a replicação autoritativa para todos os outros DCs da floresta.

Procedimento Passo a Passo

  1. Reinicie o Controlador de Domínio pressionando F8 e selecione Directory Services Restore Mode (DSRM).
  2. Efetue login com a conta de Administrador do DSRM.
  3. Restaure o snapshot do Active Directory via GBOC Agent.
  4. Execute o script autoritativo gerado para marcar a OU como autoritativa.
  5. Reinicie o servidor em modo normal.
